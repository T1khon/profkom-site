# Сайт Профкома Политеха

Статический сайт: HTML + CSS + немного JS, без сборки. Работает на любом хостинге.

## Как посмотреть
Откройте `index.html` в браузере или запустите в этой папке:
```
python3 -m http.server 5173
```
и зайдите на http://localhost:5173

## Что где лежит
- `js/data.js` — **контакты и новости**. Чтобы добавить новость, скопируйте блок в начало списка `NEWS` и поменяйте текст.
- `css/style.css` — стили. Цвета и шрифт — в самом начале файла (`:root`).
- `js/main.js` — общие шапка, подвал, меню, логотип, 3D-объекты, лента новостей.
- `img/photos/` — фото, `img/3d/` — 3D-объекты, `img/logo.svg` и `img/partners.svg` — из макета.
- `*.html` — страницы.

## Что ещё нужно заменить (поиск по `TODO`)
- состав аппарата на странице «Команда», файлы документов (`docs/`);
- даты и тексты новостей-примеров в `js/data.js`.

## Шрифт
Gilroy (Medium, Semibold, Bold, Extrabold, Heavy) лежит в `fonts/` и подключается в начале `css/style.css`.
Шрифт платный — для публикации нужна веб-лицензия. Если в покупке есть официальный веб-комплект (.woff2),
замените им файлы в `fonts/` и поправьте пути в `@font-face`.
